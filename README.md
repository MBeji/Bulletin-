# Bulletin de Notes (Student Grade Calculator)

## Description

Ceci est une application web côté client qui permet aux étudiants de calculer leurs moyennes de matières et leur moyenne générale, ainsi que la mention obtenue. Les utilisateurs peuvent entrer des notes pour différentes matières, spécifier les coefficients, et l'application mettra à jour dynamiquement les moyennes. Il est également possible d'ajouter ou de supprimer des matières.

This is a client-side web application that allows students to calculate their subject averages and overall grade average, along with the corresponding mention (e.g., Très Bien, Bien, etc.). Users can input grades for various subjects, specify coefficients, and the application will dynamically update the averages. It's also possible to add or remove subjects.

## Features

*   Dynamic calculation of subject averages.
*   Dynamic calculation of overall average and mention.
*   Ability to add new subjects with custom names and coefficients.
*   Ability to remove subjects from the list.
*   Responsive design for use on different screen sizes.
*   Data is stored locally in the browser session (no backend database).
*   User interface in French.

## Files

*   `index.html`: The main HTML structure of the application.
*   `style.css`: Contains all the styles for the application.
*   `script.js`: Contains all the JavaScript logic for calculations, DOM manipulation, and event handling.

## How to Use / View

1.  Clone this repository or download the files (`index.html`, `style.css`, `script.js`).
2.  Open the `index.html` file in any modern web browser.

## Deployment

This project is a purely static website. To deploy it:

1.  Ensure `index.html`, `style.css`, and `script.js` are in the root directory of your project.
2.  Upload these three files to any static web hosting service. Examples include:
    *   **GitHub Pages:** Create a new repository (or use an existing one), push the files, and enable GitHub Pages in the repository settings.
    *   **Netlify:** Drag and drop the project folder (containing the three files) into the Netlify deploy interface.
    *   **Vercel:** Connect your Git repository or upload the project folder.
    *   Any other web server capable of serving static files.

No build steps or server-side configurations are required.
